# 板块评分评价方法

## 目的

本框架用于检验 `sector-score-v0.2` 的强度、机会和风险是否包含稳定的远期信息，并与简单基准公平比较。它只读取已经落盘的正式收盘派生记录，不采集数据、不修改权重、不发布看板，也不生成交易指令。

所有结果固定标记为 `CALCULATION_ONLY` 和 `liveVerified=false`。合成样本只能证明计算正确，不能证明预测有效；少量真实交易日也只能形成初步证据。

## 评价对象

行业和概念分别评价，不混合排名。

| 维度／基准 | 方向 | 主要问题 |
|---|---|---|
| 强度 | 高分更好 | 强势板块能否延续并取得更高相对收益 |
| 机会 | 高分更好 | 低位改善板块能否在随后数日取得更高相对收益 |
| 风险 | 原始高分更差 | 高风险是否对应更高亏损率和更大路径回撤 |
| 5日收益 | 高值更好 | 短动量基准 |
| 20日收益 | 高值更好 | 中期动量基准 |
| 20日相对强度 | 高值更好 | 相对动量基准 |
| 位置组件 | 高值更好 | 机会分的位置基准 |

固定比较关系：强度对比5日收益、20日收益和20日相对强度；机会对比位置、5日收益和20日收益。风险暂不宣称存在等价收益基准，单独检验亏损与回撤识别。

## 时间与样本规则

- 评分必须来自正式收盘，上海时间15:00至15:30可用。
- 远期结果从下一个明确的官方交易日开始，评价1、3、5、10个交易日。
- 不跨过缺失交易日；任一评分日中的一个合格板块缺少远期收益，整日样本作废，避免幸存者偏差。
- 模型与基准只在同一天、同一批可用板块的交集上比较；各自原生覆盖率另外披露。
- 强度、机会、风险要求对应轴完整度至少70%；机会还要求至少20个有效历史收盘。
- 少于20个成熟评分日时，指标继续展示，但证据状态为 `INSUFFICIENT_EVIDENCE`。

## 指标

- **Rank IC**：评分排名与远期收益排名的 Spearman 相关。风险先反向，因此正值表示低风险板块后续表现更好。
- **IC正值率**：有效日期中 Rank IC 大于0的比例。
- **IC信息比率**：日度 Rank IC 均值除以样本标准差；少于两个有效IC或标准差为0时为空。
- **分组差**：最高20%板块与最低20%板块的平均复利远期收益之差。
- **命中率**：最高20%板块中跑赢当日同一合格范围平均收益的比例。
- **最大回撤**：最高组从初始财富1开始、在远期持有路径中的最差回撤。
- **名单换手率**：相邻有分数日期之间最高20%名单的替换比例。
- **稳健性**：按有效样本顺序分成早／中／晚三段，并报告逐日、逐板块剔除后的最小分组差。
- **风险专项**：原始最高风险20%减最低风险20%的负收益率差和最大回撤差；正值才符合风险定义。

## 运行

准备私有正式历史状态和经过核验的官方日期JSON数组：

```bash
python3 -m tools.market_dashboard.rotation_evaluation \
  --state /absolute/private/last-success.json \
  --calendar /absolute/private/official-dates.json
```

默认向标准输出写JSON。生成可读报告：

```bash
python3 -m tools.market_dashboard.rotation_evaluation \
  --state /absolute/private/last-success.json \
  --calendar /absolute/private/official-dates.json \
  --format markdown > /absolute/private/sector-score-evaluation.md
```

工具不主动写文件。无效输入退出码为1，只返回 `INVALID_EVALUATION_INPUT`，不输出堆栈、供应商原始数据或凭据。

## 如何据此修改评分

1. 保留 `sector-score-v0.2` 作为固定基准。
2. 等每个周期形成足够成熟样本后，先检查方向、覆盖和稳健性，不先看单一累计收益。
3. 新方法必须与简单基准在共同样本上比较。
4. 只有在多个周期、多个时间段和逐项剔除后仍有一致改善，才提出新权重。
5. 新方法升级评分版本并影子并行，不覆盖旧历史。

本框架不自动搜索最优权重，避免在同一评价窗口中反复调参造成过拟合。后续若加入交易成本、概念成分重叠校正或滚动训练／验证／测试，必须升级评价 schema 并保留旧报告。
