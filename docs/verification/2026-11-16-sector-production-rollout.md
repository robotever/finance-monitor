## 自动任务与首日待验收证据

稳定 checkout 合并并推送后，父项目私有 `.env` 原子设置：

```text
MARKET_DASHBOARD_ROTATION_SHADOW=1
MARKET_DASHBOARD_ROTATION_PUBLISH=1
```

LaunchAgent 保持 `com.robot-ever.newsmonitor.market-dashboard`、300 秒间隔、稳定 checkout wrapper；本轮不 `kickstart`。下一个候选自然交易日为 2026-11-16（上海时间），仍须由当批 Wind 市场日期证明其为有效交易日。

首个真实运行后只记录安全摘要，不复制供应商原始响应或凭证：

| 证据 | 待记录值 / 通过标准 |
| --- | --- |
| 市场日期与 session | 当日上海日期；09:45、11:30、14:00 或 close 的自然窗口 |
| Wind 身份数量 | 行业 35；概念目标 75，实际身份与缺失原因如实披露 |
| 完整度 | 两个 universe 的中位数、最低候选完整度，不补零 |
| 共享额度 | 同一唤醒中 v2/v3 重叠批次只采一次；记录实际积分消耗 |
