# 财联社快讯接入与固定栏清理验收

用户授权直接接入、云端自测后上线，并移除Investing中文、新浪财经股票、格隆汇固定新闻卡片。

## 实现

新增cls-news纯解析器，支持公开页inline赋值及标准Next JSON script，只做JSON解析，不eval第三方脚本；固定URL、大小/超时边界、非结构化页面失败关闭。现有normalizer加入ctime、原文id链接、A/B重要级别与股票关联；广告不入流。统一财经筛选、2h新鲜度、未来日期拒绝、去重和故障隔离保持。固定来源白名单及卡片元数据同时去掉三项；旧cailian固定卡片不恢复。
