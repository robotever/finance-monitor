# 实时首列与倒序轮动验收

## 成分股涨幅榜

本地详情加入按当日涨幅降序的成分股榜，默认显示前 10 名，可展开全部。展示股票名称、完整代码、涨幅、价格和成交额，附成分日期、有效行情数和行情时间。停牌及缺失行情保留为无排名条目，不补零。同涨幅按完整代码确定顺序。

数据复用私有 SQLite 的同花顺成分关系与个股快照；读取时以板块快照的采集时间为截止，排除后续采集和超过 20 分钟的旧行情，不因点击而向供应商请求行情。历史日期使用现有 `hithink-breadth/live-panel.csv` 的前复权价格收益；界面明确标识前复权收盘价，不与今天的最新价混用。无当日成分快照时选择截至该日最近的一版；只有未来版本可用时明确标识当前成分回填。

股票名称使用同花顺 `symbol list` 的本地私有缓存 `hithink-live/stock-symbols.json`，本轮获取 5,583 条（沪深北 A 股）。名称采用当前名称；新增股票未命中缓存时保留代码并显示名称暂缺。名称缓存需要后续按需刷新，不影响行情 15 分钟采集。该文件属于忽略目录，不进入仓库。

验证覆盖：成分版本选择、后续行情排除、零涨幅保留、缺失与停牌不排名、历史日期收益及单位；真实光刻胶板块 80 / 80 只有效行情。仅更新本地详情，公网首页及评分不变。

本轮验证：28 项 Node 专项测试及 1 项 Python 综合用例通过，生产构建通过；浏览器确认前 10／全部 80 切换、11-16 历史榜单切换，390 像素手机宽度页面无横向溢出。详情打开时检测到新批次会同步重取详情，保留所选历史日期；仍只读本地数据。截图保存于忽略目录 `output/playwright/hithink-constituent-ranking.png` 与 `hithink-constituent-mobile.png`。

- 日期由左向右按交易日降序排列，最多 15 列；最新有效盘中日期参与每日选取，后续批次覆盖同一天而不增加重复列。没有当日成功快照时不制造当日数据。
- 正式读取接口合并当前交易日最新已激活批次和此前正式收盘日，仍隔离未激活、跨版本及缺失记录。盘中列使用 `liveDate` 明确标记；前端严格验证日期倒序和数值列对齐。
- 本地预览每次请求只读取一次权威 `current-snapshot.json`，页面每 30 秒检查更新，并在重新获得焦点时刷新；刷新页面或轮询不会请求供应商 API。
- 历史重建数据保留实际可得时间，和当日真实盘中数据分别标识。风险升温榜先计算相对前一个交易日的风险变化再筛选，修复此前补入变化值却未重新筛选的预览缺陷。
- 浏览器验证：最左为 `2026-11-17 · 盘中`，随后 `2026-11-16`、`2026-11-13`；风险维度同样倒序，风险升温榜已有数据。
- 验证：23 项本地预览／v4 读取／UI 专项测试通过，生产构建通过。历史接口缩减查询投影，仅取该维度分数、排名和必要元数据。

本地启动（保持原链接，仅读本机已采集数据）：

```sh
node tools/market_dashboard/hithink_preview_server.mjs
```

## 涨幅默认排序

轮动矩阵新增 `return1d` 维度，默认以其排序并显示带符号的两位小数百分比。强度／机会／风险分数及首页三榜保持原规则。每个市场日期在对应行业／概念宇宙内独立按原始当日涨幅降序排名，同涨幅按代码确定顺序；缺失值不参与排名，显示“—”。接口、前端契约和本地读取保持相同规则，不把百分数当成 0–100 整数评分。

浏览器实测：当日第一列显示光刻胶及实际涨幅；2026-11-16 第一名证金持股 +1.43%、11-13 第一名猪肉 +2.15%，与用户提供的同花顺历史截图一致。26 项本地预览／读取／UI 专项测试通过，生产构建通过。

## 紧凑排版

独立验收页将长卡片改为板块／涨幅／强度／机会／风险表格，列表限高滚动；历史轮动移至行业三榜之后，矩阵行高由 108px 压至约 48px。概念观察、完整目录和数据说明默认折叠，详情使用一张紧凑历史表，评分依据保留为可展开区。正式首页组件和数据计算不变。

同一 558px 浏览器宽度、相同数据下，默认文档高度由 20,226px 降至 1,380px；轮动矩阵起始位置由 18,871px 前移至约 613px。浏览器复验核心 25／动态 10、代码搜索单行结果、16 日详情及默认折叠状态，无页面横向溢出。JS 语法检查及 3 项本地数据契约测试通过。
