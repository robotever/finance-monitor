# 全球联动图表与按钮修复

## 原因

黄金、WTI原油、离岸人民币使用TradingView嵌入图表。线上DOM中手动插入的空widget容器高度100%，第三方脚本另追加100%高度的实际iframe包装，后者被推到宿主之外并被卡片overflow:hidden裁剪。线上黄金宿主top432、height300，前置空容器占满整个高度。不是无行情。

另外五项为自绘SVG，原先没有缩放控制，不属于隐藏了TradingView按钮。

## 修复

- 移除额外空容器，让嵌入脚本直接在固定高度宿主内生成唯一图表包装。保留图表来源、既有顶部工具栏配置、延迟说明和失败重试。
- 五项自绘图表添加始终可见的放大、缩小、重置视图、刷新行情按钮。放大仅显示已有数据的最近1/2、1/4时段，不请求或声称新的历史周期；曲线、悬浮读数和时间轴同步，切换品种重置视图。
- 不更换数据源、行情口径或更新频率。

## 验证

- 先新增缩放窗口测试，确认旧实现失败，再实现；定向市场图表测试9/9通过。
- vue-tsc及production-rotation构建通过。
- 云端逐项检查三种嵌入图表边界、五种自绘控件、缩放重置及手机宽度。结果在上线前记录。

预览034c288b：三个iframe均与宿主同一top432、height300、width980，无前置空白；五项图表均有4个控件，放大曲线路径改变且重置恢复原路径。390px无横向溢出。手机黄金实际加载8个canvas，显示价格、曲线和1分/30分/1小时/15分工具栏；不以iframe存在代替图表完成加载的验证。

原油等待行情填入后显示WTI原油差价合约83.61，离岸人民币显示6.672230；两者均有canvas与周期工具栏。周末价格仅为供应商最近报价，不代表交易中。最终图表与滚动相关测试11/11通过。
