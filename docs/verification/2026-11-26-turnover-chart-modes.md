# 历史量能图指标切换

用户要求历史图可以选择“当日成交额”和“较昨日收盘”。本轮仅改共用前端，不改数据源、数据库或采集。

## 计算和验收条件

- 默认当日成交额；新增两个高亮按钮，可与五市场、月/年、缩放/平移组合使用。
- 较昨日收盘 = 当日全天成交额 - 上一交易日全天成交额，纵轴亿元；读数同时显示金额和百分比。
- 在完整历史上先计算差值再截取显示窗口，防止每个月首个可见点错误留空或串基准。
- 第一条历史没有上一交易日基准时留空；任一相邻金额缺失时留空，不跨缺失点补算。上日为零时金额差保留，比例留空。
- 负值正确显示，增加零轴线；切换回金额仍保持非负金额的原尺度。数据表不受切换影响。
