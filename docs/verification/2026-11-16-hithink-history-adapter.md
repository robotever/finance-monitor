# 同花顺历史适配层验证记录

日期：2026-11-16

## 范围

验证 `tools.market_dashboard.hithink_history` 能否在不读取凭据、不输出价格明细和不写数据库的前提下，通过同花顺官方 CLI 查询共享 DuckDB 的前复权日线。

## 真实只读样本

- 证券：`600519.SH`、`000001.SZ`；
- 区间：2026-11-10 至 2026-11-13；
- 口径：前复权 `qfq`；
- 请求证券：2；返回证券：2；缺失证券：0；
- 返回日线：8；首日：2026-11-10；末日：2026-11-13；
- 分页：1；完整状态：`true`。

适配器摘要与同一数据库的官方 CLI 直接小样本查询在行数、日期边界和证券覆盖上相符。验证输出仅保留 `hithink-history-audit-v1` 汇总，未包含价格、供应商响应、请求 ID、数据库内部路径或 API Key。

另用 `600519.SH` 的 2023-01-01 至 2026-11-13 前复权区间验证真实分页：返回 935 条记录、2023-01-03 至 2026-11-13、2 页、完整状态 `true`。这证明官方 CLI 实际接受适配器使用的固定排序、`limit 500` 和 `offset` 分页组合。

## 自动化验证

单元测试覆盖：

- 三种固定复权视图；
- 多页读取和稳定排序；
- 非法代码、日期、分页和相对路径在调用外部工具前拒绝；
- 截断、计数不符、未知证券、越界日期、非正／非有限价格和重复日期失败关闭；
- 缺失证券显式披露；
- CLI 失败只返回安全错误码。

## 边界

本记录只证明股票级历史读取和审计链路可用，不证明现有 Wind 行业／概念与同花顺行业目录的身份一致，也不授权用当前成份快照回算历史板块。生产评分、Cloudflare 数据和盘中采集均未改变。
