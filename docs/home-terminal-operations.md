## 财经快讯

`/api/news/live` 在Cloudflare按访问拉取和短缓存，网页每60秒检查。无需Mac采集和LLM。当前启用华尔街见闻全球快讯、金十中文快讯；MktNews本机可返回但Cloudflare实测失败，保留适配代码但不进入当前轮询名单。原来源卡片保留阅读功能，每源最多10条，每5分钟检查，不进入实时流。

- 使用华尔街见闻 `display_time`、金十 `time` 真实发布时间。无时区的金十时间明确按北京时间解析。
- 按时间倒序，精确标题及20分钟内包含式长标题去重。保留多来源说明；不同查询参数id不得误合并，只删除utm/fbclid/gclid等跟踪参数。
- 拒绝未知、非法或未来发布时间。最多100条，最近2小时以外退出；浏览器每10秒只筛过期，不重复全量去重。
- 顶部最多显示最新20条，右侧显示完整有效流。两处均支持暂停；悬停及键盘焦点暂停，用户暂停后可手动滚动单份列表。减少动画偏好直接显示静态列表。
- 标题只做标签清洗，不调用大模型翻译、摘要或真假判断。跨语言/改写新闻不承诺语义完全去重。
- 快讯源故障独立报告，未过期消息可保留；超过2小时必须退场，不用抓取时间延长寿命，也不用演示数据填充。
- “7×24”指可全天读取的财经快讯流，不保证任何时段有新消息，也不承诺上游无延迟。页面关闭后不额外常驻采集/存储新闻历史。

## 布局与维护

首页 `HomeView.vue`、统一风格 `terminal.css`、固定行情 `FixedMarketCharts.vue`；模型位于 `src/features/{live-news,market-watch}`。顶部与右侧共用 `useNewsStore().tickerItems`。老的研究雷达仍沿用原数据与评分，不把首页新行情当评分输入；债务风险折叠显示，板块入口指向 `/sectors/research`。

新增模型/API测试覆盖时间、过期、去重、查询id、故障隔离、非执行式解析、时区、允许名单、分时横轴。生产构建 `npm run build:production-rotation`；完整测试 `npm test`。旧债务模型两条固定日期样例补显式时钟，避免日期推移让样例过期，不改变其生产算法。

部署仍为Cloudflare Pages newsmonitor。构建会清空dist，部署前需恢复原 `dist/data/sector-research` 静态归档（本轮从旧部署保留491文档），云端D1实时板块数据不作迁移或重写。首页图表与快讯在云端按访问获取；板块仍依赖Mac采集，架构不能混淆。
