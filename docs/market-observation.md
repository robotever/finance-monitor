# 市场观测指标 v1

首版包含市场广度、趋势覆盖、量能结构、封板与接力，龙虎榜和异动折叠展示。它是独立的原值统计模块，不生成综合分，不改变研究雷达或板块的强度、机会、风险评分。

## 数据与时间

生产采集使用同花顺扶摇 REST API，沿用已有私有凭据 helper；浏览器不连接带凭据的数据源。全 A 股快照分页取全，代码唯一、页间总体数量相同，采样跨度不超过五分钟，且日期必须为上海当前交易日。当前范围为沪深北全 A（含 ST），无有效价格、成交量或成交额的证券排除；有效样本与排除数量可在详情查看。

每日历史来自共享 `data/hithink/market.duckdb` 的官方 CLI **只读导出**；不修改该数据库。使用原始日线及最新公司行动公告，按当前 CLI 的乘法调整规则重建一致价格面板。未来除权事件排除，缓存核对数据库时间、事件日期、方法版本和文件摘要。此口径不保证与 REST 图表的前复权算法相同；已抽查近期分红证券，差异保留在方法说明，不伪称完全相同。

趋势及日量比较使用前一交易日的已完成日线，页面标为“日线”。盘中广度、成交额及接力分别保留来源时间；不将前一日趋势显示成盘中实时结果。所有连续窗口以官方交易日历核验，不能用数据库中恰好存在的日期替代交易日历。未满窗口、新股、停牌或历史缺日按指标排除，样本数可悬停查看。

## 指标定义

| 组 | 指标 | 计算 |
|---|---|---|
| 广度 | 上涨占比 | 当前有效样本涨幅大于零家数 / 有效交易家数 |
| 广度 | 上涨／下跌家数 | 当前有效样本涨幅分别大于／小于零的数量；平盘单列 |
| 广度 | 涨跌幅中位数 | 有效样本当日涨幅中位数 |
| 趋势 | 站上20／60日均线占比 | 前一交易日调整后收盘高于含该日20／60日均价的家数 / 足量连续历史样本 |
| 趋势 | 创20／60日新高／新低占比 | 前一交易日收盘严格超过／低于此前20／60个交易日收盘极值；各需21／61日连续样本 |
| 量能 | 全市场成交额 | 当前有效样本当日累计成交额合计，元转亿元 |
| 量能 | 成交额前10%个股占比 | 按成交额降序取向上取整的10%有效样本，成交额 / 全样本成交额 |
| 量能 | 历史样本成交额/前20日均值 | 固定连续61日、每天均有成交额的样本；前一日成交额 / 再前20日平均成交额 |
| 量能 | 历史样本成交额60日分位 | 同一固定样本前一日总成交额，在再前60日中小于等于它的比例；不是盘中金额与全天金额比较 |
| 封板 | 涨停家数、封板率 | 同一个涨停统计响应的涨停数与封板率；封板率由0–1转百分比 |
| 封板 | 跌停家数 | 独立完整跌停池家数，保留其时间 |
| 接力 | 昨日涨停股今日均涨幅 | 前一交易日完整涨停池与今日有效行情按代码相交后的平均涨幅 |
| 接力 | 昨日涨停股今日晋级率 | 上述匹配样本中在今日完整涨停池内的比例，匹配/原池数量列在详情 |

共19项。涨跌区间分布互斥且合计必须等于有效交易数量。封板统计的涨停、炸板、触板须同一响应相互一致；不把来源口径不同或重叠的池相加。连板梯队在详情保留。龙虎榜读取前一交易日机构榜：净额为**机构净额**，买卖额为**榜单总额**，一日/三日记录分别保留，不能混加。异动展示来源当前监控区间，并非当日新增事件清单。

## 运行链路

- `market_observation_data.py` 采集/汇总；`market_observation_history.py` 管理只读历史导出及调整缓存。
- `market_observation_service.py` 加锁、校验候选、原子替换快照，再鉴权发布；失败不替换成功快照。未知异常只记录安全类别。
- 私有状态：项目根 `state/market-observation/`；供应商响应和中间日线留在 `market-observation-private/`，不进入 Git 或云端。
- 本地 `/api/market-observation` 读取相同已验证快照；完全离线时附加缓存状态，日期不改写。
- 云端 `0009_market_observation.sql` 新增独立 `market_observation_latest`；POST 复用既有发布令牌，严格字段/日期/样本/单位/大小/源URL校验，拒绝旧快照。既有板块、ETF、研究雷达表不改动。
- 共享 `MarketObservation.vue` 四卡展示；五分钟检查最新已发布快照，刷新按钮只读取发布结果，不能强行使供应商生成新行情。请求失败保留当前数据及时间。

独立 LaunchAgent `com.robot-ever.finance-monitor.market-observation` 指向稳定 checkout，每五分钟唤醒，上海工作日09:35–11:35、13:00–15:35按15分钟桶执行，16:00–16:15补查详情；官方非交易日先查日历后退出，失败最短两分钟再试。Mac需开机、联网且用户已登录；这仍是“Mac采集、云端展示”的架构，未迁移为云端采集。

安装：`python3 ops/macos/install-market-observation-service.py --enable`。手动核查可用既有包装器 `--market-observation --force --no-publish`；正式发布去掉 `--no-publish`，包装器私下加载项目环境，勿在命令行粘贴密钥。

## 边界与回滚

缺值显示“—”，详情说明原因；不补零，不因空集合生成100%分位。龙虎榜或异动请求失败与“成功但无记录”分别展示。当前有效股票集合用于历史统计，是当前样本回看，不能作为严格无幸存者偏差回测。首版未提供长期指标曲线或新的预测分数。

回滚前端至上一部署可立即隐藏模块；停用独立LaunchAgent可停止采集。新表与旧功能隔离，保留其数据无需删除历史表。两端需共同回滚并实测，见开发规范。
