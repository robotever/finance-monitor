# 沪深300 ETF资金观察

用户批准自动实现与上线、补齐深交所，并要求本地与线上分别验证。位置：市场研究雷达内，在现有全局/A股及风格评分后，左侧资金观察、右侧比例历史图，手机上下排列；不改原三轴评分。

固定四只核心ETF：510300/510310/510330/159919。不称全体沪深300ETF，不加总不同ETF原始份额作为金额，不将份额增减归因为国家队。上交所份额为当日清算后万份；深交所历史按size_date，T日晚间参考，T+1早间为准。保留日期与来源。

展示各ETF总份额、1/5/20交易日变化；日净申购估算为拆分调整后的份额增量乘同日单位净值，按日计算后汇总。拆分无法确认时该日估算不发布。比例=四只ETF同日份额×同日单位净值之和/同日沪深300普通A股流通市值；不可用总市值、自由流通市值或指数点位常数代替。无同日数据留空，历史不前向补齐。净资产估算非股票持仓精确穿透。

图表采用本地SVG交互，时间范围、悬停读数、缩放；不依赖TradingView/CDN。比率以百分比，增减以百分点/亿份/亿元区分。数据日频，每日自动核验；离线保留缓存原日期，异常不刷新成假实时。

架构：纯模型校验/衍生指标 + 只读公开源采集器 + 有凭据的D1发布 + 双端同一JSON契约 + Vue共享视图。私有凭据不进前端。若历史分母无法验证，只发布已验证份额，明确比例未完成，不能宣称完整交付。

替代方案：直接TradingView嵌入无此自定义代码；用指数点位推算历史流通市值会引入口径错误，均不采用。
