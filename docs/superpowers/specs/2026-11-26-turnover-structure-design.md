# 量能结构扩展

用户指定五行：全市场、沪市、深市、创业板、科创板；两个数据列为当日累计成交额和较前一交易日同时间变化（金额及百分比），下方一年日成交额交互图。全市场沿用沪深北A股含ST/CDR，创业板与科创板为深/沪子集，不能将五行相加。

沿用Vue/Python/Pages及现有15分钟任务。选择同花顺全股票汇总作为当前范围基准，东方财富原生市场级日合计作为一年历史及昨日基准；分钟对比可用腾讯/东方财富公开多日分时，但须确认完整市场口径（创业板综排除证券补齐，沪A加入CDR），并与前一日完整日线核对。不能用成份样本或昨日全天冒充同时刻。分钟缺失/口径不通过时保留当日金额，变化留空并在详情说明；不推算或插值。

扩展现有market-observation-v1兼容可选turnover字段，其内部turnover-structure-v1严格契约；原19项及分数不改。Sources仅固定公开来源，凭据留私有。UI以新五行替换原量能四指标，原四项收入折叠详情。历史图默认全市场一年，五市场可切换，日频实值，不画假实时价格。

实现选择：直接指数金额最省调用但不能保证板块完整，已发现创业板差43只/约43亿元；逐股分钟全市场过重；采用公开市场分时+明确补集且以日线核验，未通过则失败关闭。详细取数实现由开发根据实测决定，不视为用户确认具体供应商算法。

## 实测后的数据选择

原个股日线缺行不能可靠区分停牌/漏采，弃用该历史汇总。验证妙想原生五市场TVAL日频原始元值后，采用其完整一年市场合计作为历史与昨日基准；同花顺快照保留当前范围。盘中共同分钟与基准核对，15:30后明确改为全天比较，不伪造分钟时间。
