# A股市场观测指标首版

用户已批准按建议实施并自动上线，两端实际页面分别验收。新模块位于市场研究雷达之后、跨市场风险之前，独立于原评分，使用四组可解释指标，不引入新综合分。

- 市场广度：全A实时涨跌分布、上涨占比、涨跌家数与中位涨跌幅；有效交易样本排除停牌／缺失，不把空值算零。沪深北A股含ST，口径写明。
- 趋势覆盖：最近已确认完整日线的20/60日均线覆盖、突破前20/60日收盘高低点占比。必须有足够且日期合规的历史，样本分母明确，不用旧日线冒充当前实时。
- 量能结构：全A成交额、成交额前10%股票集中度；盘后总成交额相对20日均值／历史分位，盘中不直接除全天值并标成同比放量。
- 封板与接力：涨跌停、封板率、连板分档；昨日涨停股今日有效样本收益及同股晋级比例。优先同口径官方统计；股票池全分页去重，炸板与封板可重叠，不混加计数。

龙虎榜机构净买卖与异动监控收进展开详情，保留各自实际日期和失败状态。龙虎榜不当作全市场资金流。新高新低为收盘价定义；趋势盘后口径与当前盘中快照分开标注。

架构：同花顺REST及既有只读历史 → 有锁的Mac15分钟生产者 → 严格标准化聚合JSON → 独立D1表／本地文件 → 共用Vue模块。本机凭据复用，不进入浏览器；不修改其它工程历史库或原评分表。离线/请求失败保留上次数据与原日期。首次可用历史优先复用并核验，不等待积累交易日。

视图：统一标题字号、真实快照时间和刷新按钮；四卡紧凑网格，手机自适应；细节折叠，缺值说明定位到指标。已有ETF、雷达、新闻与板块入口保留。
