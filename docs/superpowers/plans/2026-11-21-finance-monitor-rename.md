# Finance Monitor 改名计划

用户明确授权将项目、首页、GitHub及原NewsMonitor名称统一为Finance Monitor。无需再逐项确认。

1. 盘点UI/包/文档/仓库/Cloudflare/本机任务/路径，先做身份及授权核验。
2. 改UI、元信息与主动引用，维护旧网址与旧路径兼容；历史验收URL保持原值。
3. GitHub仓库改finance-monitor并更新远端；Cloudflare能原位改名则原位改，不能时安全建立新入口复用原D1。D1不可改名时保留同一UUID，禁止为了名称重建历史数据库。
4. 回归测试、构建、云端验证真实快讯/图表/板块批次；发布新名称。
5. 本机任务和稳定目录迁移时保留兼容、验证没有双采集/双发布；受Codex管理的活动工作树仅在可安全登记时移动。
6. 更新操作文档、版本记录及剩余兼容项，提交推送并明确新入口。
