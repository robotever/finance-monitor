# 机会评分 v0.4

2026-11-22按用户确认修正：机会表示历史价格低位的观察吸引力，强度表示当前趋势/广度/成交承接，风险表示下行压力。高机会、低强度、高风险可以并存。

## 公式

位置因子分别对60/250日历史价格分位p计算100-p，各50%合成，越低得分越高；缺失、非法分位不置零。原有60日最低20观测、250日需250观测的数据要求保留。

机会名义权重：位置60%、上涨广度改善15%、动量改善10%、成交参与度回暖10%、相对基准转折5%。其余四个原子的归一化算法不变，改善提供额外加分。不再因改善证据少于2类封顶69；改善证据计数仍展示。minimumCloses=20、机会有效覆盖≥70保留，必要输入不够留空。现有缺失处理和覆盖算法保留，名义权重不是缺失情况下的精确贡献。

强度/风险公式、最新值及历史值不变；潜在榜原条件机会≥70、强度<70、风险<70、完整度≥70、非拥挤不变。此次修正计分定义，不调整榜单阈值填榜。

## 解释边界

价格低位不等于估值低；低位不代表止跌。其他因子不变时，历史分位下降必定增加位置分；实际总机会分还受四项改善信号与滚动窗口变化影响，不保证每次下跌总分都上升。分数变化不是收益预测准确率。60/40权重是本轮可解释方案，尚无收益优越性的回测结论。

## 版本与历史

独立评分版本sector-score-v0.4。仅用已存原始分位/归一化原子重算15日480板块，不调用金融源，不添加事后行情。强度/风险/其排名、非位置原子、所有行情指标、来源和可得时间逐值核对不变。当前成分回填原有近似标记保留，不能声称历史当时已发布新分数。

完整新历史先发布为新full基座，随后daily-v1只能引用新基座。0007增加独立v04 SQL表，不改写旧v4表；旧版快照和本地回滚备份保留。迁移器默认生成候选，--commit在发布/采集/存储锁下校验来源摘要，再原子更新；支持同时切换增量基座，重复运行幂等。
