# 市场研究雷达：日线版 v1

更新：2026-11-22。首页入口 `/#market-research-radar`，接口 `/api/market-radar`。

## 本轮解决的问题

原首页读取旧 v2 快照，最新观测停在11月18日，全球输入更早；尚未接通的资金、广度等因子长期拉低完整度，形成大量固定警告，历史快照不足也无法提供5日比较。本版改为云端重新获取可验证的日线，逐期回算同一版本评分。不是给旧缺失字段填零，也不将成交量称为资金净流入。

保留全球、A股和大盘／小盘／价值／成长／红利／科技八个观察对象，三个轴仍为强度、热度、风险。原板块的机会／强度／风险计算、同花顺采集、D1发布批次及定时服务不变。旧 v2 接口及文件保留供兼容和回退，首页不再加载。

## 计算

`src/features/market-radar/model.mjs` 为唯一公式实现。所有映射线性限制在0–100，因子缺失则对应轴为空，不重新分配权重；最后才取整。以下为未经收益预测回测的研究刻度。

### A股和风格

- 强度：5期收益25%（-5%至5%）、20期收益35%（-10%至10%）、距20期均线25%（-5%至5%）、距60期均线15%（-10%至10%）。
- 风格强度：上述绝对趋势占60%；相对中证全指5期表现24%（-4至4个百分点）、20期16%（-8至8个百分点）。比较必须使用相同起止日和观测间隔，缺日不混用窗口。
- 热度：本指数60期成交量分位50%（同值取中位秩）；今日成交量／此前20期均量50%（0.5倍→0、1倍→50、2倍→100）。不代表资金净流入，也不跨指数比较原始成交量。
- 风险：20期相对最高收盘价回撤40%（0至10%）、20期日收益样本标准差年化30%（10%至45%，年化乘√252）、5期下跌30%（0至6%）。风险越高表示价格压力越大。

### 全球

先严格取标普、VIX、10年名义／实际利率和美元共同日期，至少60个共同观测。名义利率与实际利率不前向填充。

- 强度：标普绝对趋势50%、VIX反向水平25%（12至40点）、5期实际利率变化反向15%（-30至30bp）、美元5期变化反向10%（-2%至2%）。
- 热度：VIX60期分位60%、标普5期变动绝对值25%（0至6%）、名义收益率5期变动绝对值15%（0至40bp）。此处是全球波动活跃度，不能与A股成交活跃度作同义归因。
- 风险：标普风险组35%、VIX水平45%、实际利率水平10%（-1%至3%）、美元5期正向变化10%（0至3%）。

### 比较与历史

最新与前1／5个完整观测点作分数差。全球为共同观测日，不一定等于连续美股交易日。展示20点历史，计算保留25点，分别用各时点之前60条数据；不以未来样本归一化。是同版历史重建，不宣称当时已及时发布或已验证预测能力。

## 更新、时区和故障

浏览器每5分钟及重新可见时请求一次；云端成功缓存5分钟、最后成功副本保存7天。指数日线仅保留上海15:15／纽约17:15之后的当日柱，提前收市日仍保守等待该时间。盘中显示上一个完整交易日，实时价格看全球联动，盘中板块看板块模块。

新鲜度按已核验交易日历的最近完整会话判断，不能用“5天内算正常”。中国按[上交所2026年日历](https://big5.sse.com.cn/site/cht/www.sse.com.cn/disclosure/dealinstruc/closed/c/c_20251222_10802510.shtml)；美国按[NYSE2026–27日历](https://www.nyse.com/trade/hours-calendars)，全球共同日另排除[联储银行额外假日](https://www.frbservices.org/about/holiday-schedules/)中的哥伦布日和退伍军人日。最新共同日未到预期日时不展示当前分数。此规则可能在发布等待窗口短暂留空，优于把旧值当新值。

**年度维护：** 中国2027年交易日历发布后须更新 `calendar.mjs` 并测试春节、国庆与跨年；现只核验中国2026年、美国2026–27年。未知年份关闭当前评分并说明日历待更新，不推测节假日。临时停市也须同步日历。Treasury在雷达独立请求当前及前一年并使用独立缓存，避免三月历史不足；既有跨市场风险模块请求口径不变。

通道失败不把旧缓存包装为有效值；相关评分／比较／图线为空，其他对象保留。主视图仅合并显示必要故障提示，原始日期、来源和权重放在折叠说明。无“完整度”“证据不足”“正常”等常驻徽标，无首页刷新按钮。

## 验证与回退

49项相关回归及生产模式构建通过；包含缺失量、未来不变性、时区收盘、同窗相对比较、旧数据失效、官方假日、跨年Treasury及部分通道失败。预览环境12通道成功，八对象24个分数和历史比较均来自真实数据。布局和生产验证另见发布记录。

回退可恢复 HomeView 的旧 MarketResearchDashboard 导入与模板，但旧快照根因仍在，不能把回退视为数据恢复。新接口独立且无数据库迁移；删除首页入口不会改变板块D1数据。
